# Build native Apple clients first

Orbis will first ship one SwiftUI multiplatform app for iOS 27 and macOS 27 plus a Raycast extension, all using the existing service on Vanta through Tailscale. Saving creates a Library entry; a separate Download action asks Cobalt to create Retained Audio on Vanta. The native apps stream that audio with system media frameworks, synchronize resume positions and one Listening Queue through Vanta, and also let the user open each Set's Source Link. Playing a Set preserves the rest of the queue, playing a Playlist replaces it, and only Sets with Retained Audio can enter it. When a Set finishes, Orbis removes it from the queue, resets its Playback Position, and starts the next Set. The apps will follow each platform's Human Interface Guidelines and use system controls and Liquid Glass rather than custom imitations. The Electron-to-web migration, Cloudflare, Alchemy, object storage, offline device copies, backward compatibility, and new deployment abstractions are deferred. This focuses the first release on fast capture and a strong native library and playback experience while reusing the existing Bun, Effect, and SQLite service.
