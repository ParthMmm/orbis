# Security audit — 2026-10-14

Five read-only reviews covered the whole repository at `00dfe8a`: server authentication and identity, per-Person authorization, process and file handling on the audio node, the Cloudflare API and web client, and the native clients with deploy, CI, and git history. Every finding was traced to a code path; two were confirmed by running them (the path-spelling bypass in workerd, the concurrent burst with a Bun lever). The threat model is ADR 0020: a small private Group, a public API, and a Host who accepts a leaked daily key as a small loss.

## Fixed in this change

| Severity | Where | Finding | Fix |
| --- | --- | --- | --- |
| Medium | `apps/server/src/app-core.ts` | The failed-attempt limit looked up the raw request path, but the router also matches `/sign-in/code/`, `//sign-in//code`, and `/SIGN-IN/CODE`, so guesses on those spellings were never counted. Confirmed in workerd: 60 guesses per spelling, no 429. | The open-route check decodes, lowercases, and collapses the path before the lookup. |
| Medium | `apps/server/src/app-core.ts` | A sign-in attempt was counted after it finished, so a burst of concurrent guesses could all pass the check. | Attempts are counted before dispatch, in `attempt-limiter.ts`. |
| Medium | `apps/server/src/admin.ts` | The Group Passcode had no minimum length. A four-digit passcode falls to one address in hours. | A passcode needs eight characters. Blank still closes joining. |
| Medium | `apps/server/src/attempt-limiter.ts` | The limit was keyed by exact address, so an IPv6 client with a /64 met no limit, and guesses spread over many addresses met none at all. The map was never pruned. | IPv6 clients share one counter per /64. One Group-wide ceiling of 100 failed sign-ins, which clears a minute after the last one. Expired entries are dropped on every count. |
| Medium | `apps/server/src/library.ts` | Any member who could see a Set could cancel another member's queued or running Download, which aborted the worker and deleted the partial file for everyone. | Only the requester or the Host can cancel a Download in flight. A finished one still answers 400. |
| Medium | `.github/workflows/*.yml` | Third-party actions ran from movable tags. React Doctor has write access to pull requests, issues, and statuses. | Every action is pinned to a commit. |
| Low | `apps/server/src/ytdlp-metadata.ts` | Metadata reads omitted `--ignore-config`, so a yt-dlp config file on the host could add `--exec`. Downloads already passed it. | Added. |
| Low | `apps/web/src/start.ts` | No HSTS header from the web Worker. | Added, one year, subdomains included. |
| Low | docs | Vanta's tailnet address was still named in current files after the host name was hidden. | Replaced with a placeholder. |

## Open, with a recommendation

| Severity | Where | Finding | Recommendation |
| --- | --- | --- | --- |
| Medium | `apps/server/src/media-store.ts`, `library.ts` | One file is capped at 2 GiB and one Person at 20 waiting Downloads, but nothing caps total stored bytes or checks free space. With auto-download on, a member can fill Vanta's data disk. | Before a claim, check free space with `statfs` and the sum of `retained_audio_bytes`; refuse above a cap. Decide the cap. |
| Low | `stream-grant-core.ts`, `node-audio-http.ts` | A stream grant is signed over Set, Person, and expiry only. Revoking the key or removing the Person leaves the audio URL valid for up to 24 hours, and Vanta has no trust store to check. | Shorten the grant to an hour, or sign the key id and check it on the Group path. |
| Low | `node-http.ts` | The Funnel still forwards `/api` to the Group. All Funnel clients share Vanta's egress address, so 21 wrong guesses through the Funnel lock every Funnel user out for a minute. | Retire the forward or limit it to audio. Kept for now by the Host's decision. |
| Low | `ytdlp.ts`, `source-url.ts` | `--max-filesize` applies only when the size is known, and `/live/<id>` is accepted, so a live stream runs until the 10-minute timeout. | Abort in the progress poll past 2 GiB; add `--match-filter "!is_live"`. |
| Low | `audio-node.ts` | The node runs yt-dlp on the command URL as the Group sends it. A compromised Group or a bootstrap import could point it at Vanta's home network. | Run `normalizeSourceUrl` on the node and refuse a URL it changes. |
| Low | `apps/server/src/app-core.ts` | Library, friend, and Listen reads have no `LIMIT`; `/events` streams per key are uncapped; metadata and Tracklist retries have no per-Person limit. | Add a limit and cursor to Listens, cap event streams per key. ADR 0020 accepts the quota spend for members. |
| Low | `apps/apple/Orbis/ClientSettings.swift` | Keychain queries do not set `kSecUseDataProtectionKeychain`, so on macOS the item may land in the login keychain, where "this device only" does not apply. Not verified on a Mac build. | Set the key on macOS and migrate the item. |
| Low | `deploy/cobalt/Dockerfile` | `npm install` without a lockfile. | Commit a lockfile and use `npm ci`. |
| Info | `bun audit` | 85 advisories. The two critical ones, `tinypool` and `proxy-addr`, are not reachable: one is the dev formatter, the other is Express inside evlog, which the server does not use. | Bump when upstream releases. |

## Checked and sound

No command injection: no shell anywhere, arguments are lists, `--` precedes every URL, and stored links are rewritten to a fixed YouTube or SoundCloud form. No path traversal: ids are server-made UUIDs looked up before any file access. Keys are 256-bit, stored as SHA-256, compared in constant time; Sign-in Codes come from `randomInt`, work once, expire in 10 minutes, and a concurrent redeem minted exactly one key. Host powers follow the Host Person on every admin route. Every friend read, Presence frame, Tracklist, and audio grant passes the ADR 0009 visibility gate; the change feed carries only a topic. All SQL is parameterized. Node keys are refused on client routes and required for import, export, and recovery. The limit reads `CF-Connecting-IP`, not a spoofable header. The web client has no HTML sinks, a per-request CSP nonce, `frame-ancestors 'none'`, and no secrets in the bundle. The Apple key lives in the Keychain as `WhenUnlockedThisDeviceOnly` with no iCloud sync, no ATS exceptions, no URL schemes, and no key in logs. CI grants no default permissions, drops checkout credentials, and puts no event data in `run:` steps. Git history holds no private keys, vendor tokens, or env files. Cobalt binds to the tailnet only and keeps its key at mode 0600.

## Not covered

No test in the repository exercises `apps/api` directly, so `/recovery`, `/node`, `/import`, and `/export` are proven only by the workerd journey. Vanta's installed units and file modes were not inspected. Whether yt-dlp hands a live download to an ffmpeg child that outlives the timeout was not traced.
