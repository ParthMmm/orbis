# Orbis × tvOS (research note)

**Date:** 2026-09-26  
**From:** atlas  
**Status:** locked into ADR 0012 + module spec

## Ask

Spec a tvOS app for Orbis; Apple stack already has the iOS/macOS client.

## Repo facts (primary)

- Repo: https://github.com/ParthMmm/orbis
- `apps/apple/project.yml`: `Orbis` / `OrbisShare` / tests → `supportedDestinations: [iOS, macOS]` only — **tvOS not enabled yet**
- Player: `apps/apple/Orbis/AudioPlayer.swift` — `AVPlayer`, `AVAudioSession` `.playback` (non-macOS), `MPNowPlayingInfoCenter`, `MPRemoteCommandCenter` play/pause
- Shells: iOS compact tabs (Home / Library / Playlists / Search) + iPad/macOS `SidebarShell`; connection via address + device token (`ConnectionView`)
- Background audio: `UIBackgroundModes` = `audio` in `Orbis/Info.plist`
- Category: music (`LSApplicationCategoryType: public.app-category.music`)

## Apple platform facts (primary)

- tvOS apps are separate binaries; share code via multiplatform target / `#if os(tvOS)` ([App Programming Guide for tvOS](https://developer.apple.com/library/archive/documentation/General/Conceptual/AppleTV_PG/))
- Focus + Siri Remote; no touch ([same](https://developer.apple.com/library/archive/documentation/General/Conceptual/AppleTV_PG/))
- Local persistence capped (~500 KB `UserDefaults`); other data must be purgeable cache / iCloud / on-demand resources ([same](https://developer.apple.com/library/archive/documentation/General/Conceptual/AppleTV_PG/))
- Background audio: `UIBackgroundModes` → `audio` ([same](https://developer.apple.com/library/archive/documentation/General/Conceptual/AppleTV_PG/); [Configuring your app for media playback](https://developer.apple.com/documentation/AVFoundation/configuring-your-app-for-media-playback))
- Top Shelf via `TVServices` / `TVTopShelfContentProvider` ([Building a Full Screen Top Shelf Extension](https://developer.apple.com/documentation/TVServices/building-a-full-screen-top-shelf-extension); deep links WWDC17-246)
- Standard video chrome (`AVPlayerViewController`) is video-centric (WWDC21-10191); Orbis is **audio Sets** — use SwiftUI Now Playing + system Now Playing info, not a fake video player

## Contrast with CarPlay (ADR 0011)

| | CarPlay | tvOS |
|---|---|---|
| Where UI runs | Car screen | Apple TV |
| Where audio runs | iPhone | Apple TV |
| UI kit | CarPlay templates only | SwiftUI + focus |
| Entitlement | `carplay-audio` Apple form | Normal tvOS provisioning |
| Downloads tab | Yes (phone local files) | No in v1 (storage limits) |

## Suggested slices

0. Enable tvOS destination; compile; connect; library list; play one Set through `AudioPlayer`
1. Focus shell (sidebar/tabs + Home rails); playlists; search; full-screen Now Playing; queue
2. Top Shelf continue / recent + `displayURL` / `playURL`
3. Pairing UX: short code or QR so tokens aren’t typed on the remote

## Open product calls (defaults chosen in ADR)

- Downloads on TV → **no tab in v1** (stream + purgeable cache only)
- Filing / share extension on TV → **out**
- Top Shelf → **post-core**
- Universal Purchase → Parth / App Store Connect when shipping
