# Orbis × CarPlay (research note)

**Date:** 2026-09-25  
**From:** atlas  
**Status:** recommendation — not implemented; no ADR yet

## Ask

CarPlay support for Orbis (self-hosted library / DJ sets).

## Category

Orbis is an **Audio** CarPlay app: browse + play owned library audio while driving.

Primary docs:
- https://developer.apple.com/carplay/
- CarPlay Developer Guide (PDF, Apple download)
- `CarPlay` framework: `CPListTemplate`, `CPNowPlayingTemplate`, `CPTemplateApplicationScene`
- MediaPlayer: `MPNowPlayingInfoCenter`, `MPRemoteCommandCenter`, `MPNowPlayingSession`

## Hard gates

1. **Apple entitlement** — request Audio category at https://developer.apple.com/carplay (`com.apple.developer.carplay-audio`). Apple must approve before device/TestFlight CarPlay works; simulator needs a CarPlay-capable provisioning profile too.
2. **Native iOS only** — lives in `apps/apple` (Swift). Not Electron, not web, not “Expo CarPlay” as the real surface. RN would still need a native CarPlay scene; Orbis already has SwiftUI multiplatform → use that.
3. **Playback on iPhone** — CarPlay is remote UI; audio session runs on the phone (`.playback` background mode), stream/file from Vanta as today.
4. **Templates only** — no custom SwiftUI / Rive on the car screen. Now Playing metadata comes from Now Playing Info Center.

## Recommended slices

### Slice 0 — Now Playing foundation (ship without entitlement)
Prereq for CarPlay and for Lock Screen / Control Center / Bluetooth head units:

- `AVAudioSession` category `.playback` + background audio capability
- Publish `MPNowPlayingInfoCenter` (title, artist/set, artwork, elapsed, duration, rate)
- Handle `MPRemoteCommandCenter` (play/pause, next/prev, maybe seek)
- Keep Orbis player state machine as single source; CarPlay/Lock Screen are views of it

### Slice 1 — CarPlay Now Playing + tab root
After entitlement:

- `CPTemplateApplicationScene` / `CPTemplateApplicationSceneDelegate`
- Root: tab or list (Library / Playlists / Recent / Downloads)
- Push `CPNowPlayingTemplate.shared` when a Set starts
- Wire remote commands to the same player as Slice 0

### Slice 2 — Browse that matches Orbis nouns
- Lists of **Sets** (not tracks as primary noun), playlists, tags/filters as list sections
- Respect ~500 row template cap — paginate or cap “All Sets”
- Artwork via `CPListItem` images (cached; don’t block UI on network)
- Offline/Downloads first if on cellular weak — product call

### Slice 3 — Safety / product policy
- No social write actions from the car (see/appear toggles stay phone-only)
- No key pasting / admin in CarPlay
- Presence: optional later “listening in car” — out of v1

## Non-goals (v1)

- CarPlay Video
- Automaker / CarPlay Ultra
- Driving-task templates
- Playing from the Mac/Electron app into CarPlay (impossible; phone must be the CarPlay endpoint)

## Fit with existing Orbis architecture

- Vanta still owns download jobs + retained audio; phone CarPlay client streams same APIs with Person API key already on device.
- Web edge (Alchemy tunnel) unrelated to CarPlay except API reachability from phone network.
- Social ADRs 0008–0010 unchanged; CarPlay is another **client** of the same read/play APIs.
