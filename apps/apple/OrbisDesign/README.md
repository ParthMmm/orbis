# OrbisDesign

The shared design system for the Orbis apps on macOS and iOS: tokens, styles, and components in one SwiftUI package.

- Source of truth: `docs/design/tokens.json`, checked against `docs/design/tokens.schema.json`. Run `bun run tokens:generate` after editing it to regenerate `Tokens/GeneratedColors.swift` and `docs/design/tokens.css`. `bun run tokens:check` fails when a generated file is stale, and `bun run check` runs it. `docs/design/tokens.css` is in `.prettierignore`, because a generated file has to match its source byte for byte.
- Colors: `Color.orbis.paper`, `.paperRaised`, `.field`, `.tint`, `.destructive`, and `OrbisColor.Category` (`.dot` for swatches, `.text` for labels). Tint means interactive; category means grouping; red means removal. Every token carries a light, a dark, and an increasedContrast value, and `DynamicColor` picks the increased one when the platform reports Increase Contrast; the generator fails the build when a text shade drops under APCA Lc 75 on `paper` or `paperRaised`, or when a colour leaves Display P3.
- Type: `Font.orbis.*` — Dynamic Type text styles only, SF Pro and SF Mono. `label` is the small uppercase mono of a listing; `timecode` is the playhead at title size, monospaced so the digits hold still; `title` is a Set's name on its own page.
- Radius: `Radius.*` — the one custom scale. Spacing uses system defaults. Listings carry no radius: `Radius.artwork` is zero, and rows are parted by hairlines, not held in cards.
- Listings: the Library, the Queue, and a Set's fields are dense and flat. `ListingRule` opens a list under its title; `ListingHeader` names a group, such as the day Sets were filed; `ListingLabel` is a field name or a count; `ListingRow` is a label, a value, and the way to change it; `TagWord` writes a Tag as `#techno` in its colour, underlined when it is the active filter. `Artwork` is the provider's 16:9 thumbnail, square, with a flat tone from the title until the image arrives, and a bar along its bottom edge when the Set is in progress. Nothing else draws on artwork, so the bar means one thing.
- Liquid Glass: standard chrome is glass on recompile. `.orbisGlass()` is for custom floating bars only: `MiniPlayer`, which docks now playing above the tab bar on every screen but the Set's own page, is one. Raised surfaces (`.orbisRaised()`) remain for sheets, the paste hero, and the playlist picker. The tinted `.orbisPrimary` button is the one glass element inside content.
- Components: `PasteHero` (which composes `LinkField`), `SourceStamp`, `TagChip`, `TagPill`, `TagInput`, `PlaylistRow`, `PlaylistPicker`, `Artwork`, `SetRow`, `SetDetail`, `MiniPlayer`, `CopyFailureButton`, and the listing pieces above. `SetRow` is artwork, title, and one data line: the creator and the length, or the resume position once listening has started, then the Tags. `SetDetail` leads with the artwork, says the title once, keeps Open as the only tinted control inside the Source row, and ends with removal. Each file carries a `#Preview` at Mac and iPhone widths in light and dark, and one at each width in a right-to-left layout covering both `.xxxLarge` and `.accessibility5` through `AccessibilitySizeMatrix`.
- States: `EmptyLibraryState`, `EmptyPlaylistState`, `NoResultsState`, `UnavailableState`, `LoadingState`. Each names what happened and states its recovery in the button's own words; `UnavailableState` takes an `OrbisFailure` and offers Try again only when retrying could change the answer. `LoadingState` redacts the real `SetRow` layout, so the list does not jump when content arrives.
- Failures: `OrbisFailure` is the heading, sentence, symbol, address, and retryability. `FailureReport` turns one into the text a person pastes into a message. An app maps its own errors to `OrbisFailure` and keeps the vocabulary.
- Motion: `OrbisMotion` names each motion and the effect it plays — `filingSucceeded` bounces, `filingFailed` wiggles, and every motion has a Reduce Motion form. Views ask for the name with `.orbisSymbolEffect(_:trigger:)` or `.orbisAnimation(_:value:)`, never for an ad-hoc animation. Triggers must change only when the motion should play, and no motion loops or runs on appear.
- Rows that can be pressed wear `.orbisRowHeight()`, which gives a touch platform the 44 points a finger needs and leaves a Mac to its pointer.
- Input rules: `LinkField` files a link once it is shaped like one; whether Orbis supports it comes back as state. `TagInput` applies the service's own Tag rules, twenty Tags of forty characters, trimmed, lowercased, and deduplicated, so nothing typed there returns refused.
- Large text and right-to-left: `.orbisAccessibilityLayout()` sets a text size and a right-to-left direction for a preview or a layout test, and `AccessibilityPreview.textSizes` names the two sizes the matrix covers, `.xxxLarge` and `.accessibility5`. Rows move their artwork above the text at `.xxxLarge` and above instead of squeezing their title, chips reflow through `ChipFlow`, which wraps a chip wider than its row inside the edge, and the paste field drops its button below at accessibility sizes. Disclosures use `chevron.forward`, which the system mirrors, never `chevron.right`.

Requires Xcode 26.1 or later; platforms iOS 26.1 and macOS 26.
