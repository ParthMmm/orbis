## Findings considered and rejected

- **Equalize 500 and 100 array caps:** wrong framing. Sets per Playlist and Playlists per Set are different dimensions. Plan 007 fixes cross-route invariant enforcement and preserves separate values.
- **Metadata retry changes enriched to failed:** an outage does change the last recorded attempt while retaining metadata, but the intended state semantics are not settled enough to prescribe a new state or preserve success. Product clarification, not a confirmed data-loss bug.
- **All rejected bodies are misreported as malformed JSON:** the existing message says “Check your request fields and send valid JSON.” It already covers field validity. More specific validation feedback may help, but the original categorical claim was overstated.
- **Synchronous enrichment, no provider in default tests, explicit-title network bypass, and the absent sequential Download worker:** documented choices in ADRs 0002/0005 or planned work, not defects to patch during this audit.
- **Bearer replay until revocation:** explicitly accepted by ADR 0004. Do not replace per-device tokens with a new signing/key ceremony without a separate decision.
- **Electron contextBridge advisory proves remote compromise:** the reviewed advisory requires loading untrusted content, which was not shown in this renderer. Affected build/archive dependencies remain a separate qualified finding.
- **Electron IPC rejection always wedges busy state:** fallback cleanup is incomplete for rejected bridge promises, but a routine reachable rejection path was not established. Lower leverage than the selected failures.
- **Search causes sibling Playlist refetches on every keystroke:** attribution was not established. Search itself is eager, but no personal-library performance measurement justifies a new cache/debounce plan here.
- **Unbounded list responses and per-member primary-key checks:** potential future growth costs, but acceptable at the documented personal scale. The confirmed correlated membership scan is separately addressed by 006.
- **Broad AppModel/Electron refactors or framework migrations:** no measured need; would expand risk without closing the specific defects.
